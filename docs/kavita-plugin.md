# Kavita Plugin

To configure the Kavita plugin:

1. Install the **Kavita** plugin.
2. In the installed plugins page, press the cog icon to open the plugin settings.
3. Fill in the required information:
    - **URL**: Your Kavita server URL. It should include the protocol (`http` or `https`) and port if necessary.
      - Example: `http://192.168.1.10:5000`
      - Example: `https://kavita.mydomain.com`
    - **API Key**: Found in your Kavita Dashboard. Go to your User Dashboard -> `3rd Party Clients` -> Copy the API Key (usually part of the OPDS URL or generated separately).
4. Press save and restart the app.
5. The Kavita plugin will now work like the other plugins.
